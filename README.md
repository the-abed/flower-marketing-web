# 🌸 Flower Marketing Website

A simple and elegant **Flower Marketing Website** built using **raw HTML and CSS**. This project showcases different types of flowers with a clean layout and responsive design.

## 📌 Project Overview

The Flower Marketing Website is a static website designed to display and promote various flower products. It is built using only **HTML5** and **CSS3**, without any frameworks or libraries.

This project is perfect for beginners who want to practice:

* HTML structure
* CSS styling
* Layout design
* Responsive design basics

---

## 🚀 Features

* 🌷 Beautiful homepage banner
* 🌹 Flower product section
* 📱 Responsive design (mobile-friendly)
* 🧾 Navigation bar
* 📩 Contact section
* 🎨 Clean and modern UI design

---

## 🛠️ Technologies Used

* **HTML5** – For structuring the website
* **CSS3** – For styling and layout

## 💻 How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Double-click on `index.html`.
4. The website will open in your browser.

No installation or dependencies required.

## 🎯 Learning Purpose

This project was created to practice basic front-end development skills using only HTML and CSS. It helps to understand:

* Semantic HTML tags
* Flexbox / basic layout techniques
* Styling components
* Responsive adjustments using media queries
